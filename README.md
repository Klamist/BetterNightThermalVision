# SPT - Better Night Thermal Vision

A SPT 4.0 BepInEx plugin for:
- Disable Blur/noise/FPS-limit ... for thermal optic and T7/Night vision helmet device
- Helmet thermal through magnified non-thermal optics, with the reticle kept readable
- Extra T7 palettes, including red-hot and ironbow

Built against SPT 4.0.13 (EFT 0.16.9.40087). This build still needs a port to SPT 4.1.

More details please visit: [SPT Forge Mod page](https://forge.sp-tarkov.com/mod/2531/better-night-thermal-vision)
